# Vellous Minecraft Animations

A dedicated Minecraft animation studio repository for creating high-retention Shorts and long-form videos.

## Goals
- Original Minecraft animated shorts
- Long-form cinematic Minecraft videos
- Original sound design and music workflow
- Reusable rigs, environments, animations, and camera systems
- GitHub-based project organization and automation

## First Project
`short-001-zombie-fight`

## Pipeline
Storyboard → Scene Setup → Animation → Audio → Render → Edit → Export

## Production Principle
The project should use original animation, original sound design, and original music by default. Third-party assets may only be added when their licenses are compatible with the intended distribution and monetization.
